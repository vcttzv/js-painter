# Автоматическая форма для голосований
Расширение, упрощающее работу с заявками на техподдержке сферы Творчества

*Путь к файлу кода в репозитории:* [js-painter/main/painter.js]([vcttzv/js-painter/blob/main/painter.js](https://github.com/vcttzv/js-painter/blob/main/painter.js))

Установленный скрипт создаёт форму для сборки поста с голосованием на странице [catwar.net/sniff?creation](https://catwar.su/sniff?creation). После загрузки DOM под полем ввода содержимого поста появляется кнопка «Создание голосований». После нажатия кнопки создаётся форма для заполнения информации о голосовании. 

![](https://i.ibb.co/fz1FvFTV/image.png "Форма для заполнения информации")

### Функции скрипта:
+ **Генерация BB-кода голосований**
  <br>После ввода всех необходимых данных и нажатия кнопки «Сгенерировать голосование» скрипт внесёт их в шаблоны Маляра и поместит в текстовый блок содержимого поста. Название поста также будет сгенерировано и вставлено в соответствующее поле автоматически
+ **Генерация опросов голосований**
  <br>После нажатия на кнопку «Сгенерировать голосование» скрипт получит информацию о количестве добавленных новых версий и создаст соответствующий опрос
+ **Добавление новых версий**
  <br>Нажатие на кнопку «Добавить новую версию» приведёт к созданию новых полей ввода, предназначенных для размещения в них ссылок на предложенные новые версии перерисовок. В дальнейшем добавленные новые версии будут использованы в генерации голосования
+ **Автоматический расчёт даты завершения**
  <br>Голосования Маляра длятся 7 дней с момента публикации поста. Скрипт автоматически подставляет дату через 7 дней от сегодняшней. Если время голосования нестандартное, можно указать дату вручную или воспользоваться кнопкой «+1», чтобы передвинуть дату на 1 день дальше
+ **Проверка изображений на соответствие требованиям**
  <br>По нажатию на кнопку «?» в поле новых версий запускается проверка изображения на соответствие требованиям по весу файла, разрешению и формату в соответствии с типом объекта. Если всё ок, поле ввода подсвечивается зелёным и кнопка с вопросом заменяется на галочку. Если нет, поле окрашивается красным, кнопка проверки заменяется на крестик, а ниже выводится информационный блок с пояснениями об ошибках

![](https://i.ibb.co/Q1kpvHy/image.png "Проверка изображений на соответствие требованиям")

### Прочее:
+ Заполнение шаблонов голосований в коде скрипта выполнено так, чтобы в случае изменений их было легко отредактировать
+ Если добавлена только одна новая версия, в шаблоне голосования и тексте опроса не будет указываться нумерация новых версий, поскольку это не требуется. Если новых версий будет 2 и более, шаблон и текст опроса будет содержать нумерацию новых версий
+ Шаблон голосований за фоны структурно отличается от других типов голосований. Скрипт учитывает это и использует данные о выбранном типе объекта для заполнения нужного шаблона
+ В форме предусмотрены кнопки для быстрого ввода стандартных значений. По нажатию на кнопку нужное значение автоматически подставляется в соответствующее поле
+ Скрипт поддерживает мультиголосования, где нужно учесть несколько разных объектов, которые также могут отличаться по своему типу. В таком случае предлагается другая форма:
